# Cybersecurity Home Lab Assessment  

Hands-on cybersecurity vulnerability assessment lab using isolated Ubuntu virtual machines, Linux networking tools, Nmap, and controlled vulnerability validation and remediation.

## Objectives

 - Analyze an isolated network
 - Identify the Target's attack surface
 - Analyze basic host security configurations
 - Validate, Remediate, and verify a controlled infomration-dsclosure vulnerability

## Environment

 - Oracle VirtualBox
 - Ubuntu 26.04 LTS
 - Attacker and Target VMs
 - Assigned isolated `10.10.10.0/24` Network

## Tools

 - Nmap
 - `ss`
 - `ping`
 - Python HTTP server
 - Linux security tools
